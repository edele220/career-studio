拾阶 · 求职工作台
Windows x64 使用清单

一、启动

[ ] 把 Windows x64 便携 ZIP 完整解压到桌面或文档。
[ ] 打开「拾阶求职工作台」文件夹，双击「双击打开工作台.cmd」。
[ ] 浏览器通常会自动打开。如果没有，手动访问 http://127.0.0.1:8765/ 。
[ ] 使用时保持启动窗口开着。下次从同一文件夹启动即可接着用。

便携包已包含运行时。如果下载的是 GitHub 源码，请先安装 Node.js 24 LTS。
首次启动会在程序目录下创建空白 SQLite 数据库。

二、开始记录

[ ] 在「账户与设置」填写自己的称呼、目标岗位和求职偏好。
[ ] 在「岗位数据库」新增岗位。可以手填、粘贴 JD、读取公开招聘页，或者上传 JD 截图。
[ ] 在「个人经历库」补一条经历。记录任务、自己的行动、实际结果和可核对的证据。
[ ] 在「简历中心」加入经历、调整样式和栏目，再「保存为新版本」。可以导出 HTML，或通过浏览器打印存为 PDF。
[ ] 在「求职进度」记录投递、沟通、面试和下一步。

三、试用对话收件箱（可选）

[ ] 启动后，把「示例」目录里的 example-jd-01.json 复制到程序目录下的「data\对话收件箱」。
[ ] 点击「对话收件箱」，预览并确认收录。示例包含虚构岗位、经历、分析和简历草稿。
[ ] 在岗位详情查看分析，再在简历中心打开草稿。正式使用时，可让自己常用的 AI 按《对话接入.md》中的格式整理结果。

四、备份和常见问题

[ ] 定期在「账户与设置 → 导出全部数据」保存 JSON 备份。换电脑时可在新副本通过「导入备份」恢复。导入会覆盖当时打开的副本的数据。
[ ] 分享时转发发布页上的原始 ZIP。自己用过的文件夹有个人数据库和对话记录，请单独保管。
[ ] 页面打不开时，先运行启动脚本。若提示端口被占用，可关闭之前启动的工作台再试。
[ ] 公开招聘页无法读取时，可改用粘贴 JD 或截图。OCR 需要 Windows 对应的语言组件。

便携包附带 Node.js 运行时，许可和第三方声明见 runtime\NODE-LICENSE.txt。
