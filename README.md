# 拾阶 · 求职工作台

一个面向个人求职者的 Windows 本地工作台。把岗位收集、经历整理、岗位匹配、简历草稿和投递跟进串在一起，让同一条岗位记录贯穿整个求职流程。

## 能做什么

| 功能 | 操作 |
| --- | --- |
| 岗位录入 | 手动填写、粘贴 JD、读取公开招聘页，或用本机 OCR 识别截图。提取结果可以逐项校对，已有字段会保留。 |
| 经历库 | 记录工作或项目经历的任务、行动、结果、证明材料和能力标签。 |
| 岗位匹配 | 用本地规则生成匹配度、经历证据和简历调整建议，按岗位保留分析版本。 |
| 简历草稿 | 选择目标岗位和经历素材，保存多个草稿版本，导出 HTML 或通过浏览器打印为 PDF。 |
| 求职跟进 | 管理投递状态、沟通和面试记录，追踪待办和下一步。 |
| 数据管理 | 使用 SQLite 持久化记录，支持 JSON 备份和恢复。 |

## 本地运行

1. 安装 Node.js 24 LTS，然后克隆仓库或解压下载的源码。
2. 在 Windows 资源管理器里双击 `双击打开工作台.cmd`，或者在项目目录执行 `node server.js`。
3. 浏览器打开 `http://127.0.0.1:8765`。运行期间保持服务窗口开启。

首次启动会在 `data/` 创建 SQLite 数据库，无需运行 `npm install`。截图识别需要 Windows 对应语言的 OCR 组件，支持简体中文和英语。

### 试用示例

全新实例可以在「账户与设置 → 导入备份」中导入 [虚构的示例数据](demo-data.example.json)。导入会覆盖当前实例的数据。已有个人记录时，请先导出备份，或在新副本里试用。

打开「岗位数据库」查看示例岗位，再到「AI 分析」选择该岗位生成一版规则分析。随后可以在「简历中心」勾选相关经历，生成并导出草稿。

## 设计与实现

| 模块 | 实现 |
| --- | --- |
| 浏览器界面 | 原生 HTML、CSS 和 JavaScript，提供总览、岗位、分析、简历、经历、进度和设置七个页面。 |
| 本地 API | Node.js 内置 HTTP 模块提供页面和 API。岗位数据、经历、待办、跟进、简历和分析批量写入同一 SQLite 事务。 |
| 岗位提取 | 读取公开 HTTP(S) 页面，优先解析 `JobPosting` 结构化数据，再尝试从正文提取 JD。截图通过 Windows OCR 在本机处理。 |

```text
index.html          工作台界面与交互
server.js           本地 HTTP API 与 SQLite 持久化
job-import.js       招聘页读取与 OCR 调用
job-fields.js       JD 字段提取与链接分类
windows-ocr.ps1     Windows OCR 适配
demo-data.example.json  虚构示例数据
```

当前版本是单人本机应用，服务监听 `127.0.0.1`。匹配分析使用本地规则。需要登录或只在浏览器里动态加载 JD 的招聘页，通常要改用截图或粘贴正文。
