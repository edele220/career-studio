# 拾阶 · 求职工作台

面向个人求职者的 Windows 本地工作台。收集岗位、沉淀经历、设计简历、跟进投递。对话中整理出的岗位分析和简历草稿也可以归到对应岗位，后续随时回看。

## 开始使用

**Windows x64 便携版**从 [GitHub Releases](https://github.com/edele220/career-studio/releases) 下载。完整解压后双击 `双击打开工作台.cmd`。便携包自带运行时和 [使用清单](使用清单.txt)。

**从源码运行**需要 Node.js 24 LTS。在 Windows 资源管理器中双击同一个启动脚本，或在项目目录执行 `node server.js`。首次启动会在 `data/` 创建空白 SQLite 数据库，无需 `npm install`。

浏览器默认打开 `http://127.0.0.1:8765`。使用期间保持启动窗口开启。

## 能做什么

| 功能 | 操作 |
| --- | --- |
| 岗位录入 | 手动填写、粘贴 JD、读取公开招聘页，或用 Windows 本机 OCR 识别截图。提取结果可以逐项校对。 |
| 对话收件箱 | 从 UTF-8 JSON 预览和收录岗位、分析、经历或简历草稿。岗位详情可回看分析版本，并从匹配证据选取经历组装简历。 |
| 经历库 | 记录任务、行动、结果、证明材料和能力标签。已整理的经历可在不同简历中复用。 |
| 简历中心 | 自定义栏目、条目、单栏和双栏布局，也可以从四套预设样式开始。支持实时预览、默认版式、版本保存、HTML 导出和浏览器打印 PDF。 |
| 求职跟进 | 记录投递状态、沟通、面试和下一步。 |
| 数据管理 | 使用 SQLite 保存本地记录，支持 JSON 备份和恢复。 |

岗位分析在你选用的 AI 对话或本地工具中完成。工作台通过 [对话接入格式](对话接入.md) 收录和展示结果。截图识别需要 Windows 上安装对应的简体中文或英语 OCR 组件，需要登录的招聘页可改用截图或粘贴 JD。

### 试用示例

1. 启动工作台，把 [虚构对话记录](示例/example-jd-01.json) 复制到 `data/对话收件箱/`。
2. 点击「对话收件箱」，预览并确认收录。
3. 打开示例岗位的「分析记录」，再去「简历中心」编辑示例草稿。

## 设计与实现

| 模块 | 实现 |
| --- | --- |
| 界面 | 原生 HTML、CSS、JavaScript。简历内容和版式以版本快照保存。 |
| 本地服务 | Node.js 内置 HTTP 和 SQLite 模块。服务默认只监听 `127.0.0.1`。 |
| 岗位提取 | 公开网页优先解析 `JobPosting`，也能从页面文本和粘贴的 JD 提取字段。截图在 Windows 本机识别。 |
| 对话收录 | 本地文件预览和确认。岗位、分析、经历、简历草稿及收录状态在同一事务中保存。 |

```text
index.html                   工作台页面
server.js                    本地 API 与 SQLite 数据库
job-import.js / job-fields.js 招聘页读取与 JD 字段提取
windows-ocr.ps1              Windows OCR 适配
conversation-records.js      对话记录校验和收录
resume-model.js              简历内容与版式模型
resume-designer.js           简历编辑、预览与导出
```

日常使用产生的简历、经历、岗位和分析保存在本机。换电脑时可以从「账户与设置」导出自己的备份。
